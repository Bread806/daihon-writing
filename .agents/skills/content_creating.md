# 情節試寫

這個 skill 只準備片段任務、派發 `.agents/agents/writer.md`，並把試寫結果交給使用者判斷。試寫是探索情節的候選稿，不等於已定案的故事文件或正式草稿。

## 理解情境

讀取目前的故事文件、相關前文，以及 `specs/writing/劇本寫作指引.md`。掌握角色與聽眾的關係、場景位置、角色當前的情緒與行動、接下來要發生的事、這段的感情核心及預期的收尾氛圍。這些是理解情境的角度，不要求使用者填寫固定模板。

以使用者指定的片段或目前卡住的情節為範圍。能從已確認內容推得的資訊直接使用；若缺少會改變故事方向的關鍵決定，先請使用者決定，不自行新增設定。

## 派發 writer

交給 writer：已確認的故事設定、試寫片段的起點與目標、必要前文、寫作指引，以及使用者指定的篇幅或語氣。要求只寫這一小段，遵守單口音聲形式；聽眾不發聲，其反應透過主角台詞與行動暗示。以情節與情感完整為收束點，不為湊字數延長，也不在段落中途截斷。

## 交回討論

將試寫片段呈現給使用者，簡述它驗證的情節或角色選擇。依使用者意見確認要保留、修改或捨棄的方向；未經確認，不把試寫文字或其中的新設定併入故事文件。
