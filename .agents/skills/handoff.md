# 通用交接 skill

> 本檔 Skill tool 無法直接發現。執行時請用 **Read tool 讀取本檔**，再依內容執行（與其他本專案 skill 一致）。

## 兩種交接

| 類型             | 方向                                  | 情境                     | 產物               |
| -------------- | ----------------------------------- | ---------------------- | ---------------- |
| **Session 交接** | 主 agent → 主 agent（跨 session）        | 一輪工作告段落、要換新 session 接手 | `handoff.md`     |
| **Loop 迭代交接**  | 主 agent → 下一個 subagent（同 session 內） | subagent 做完一輪、要派下一輪改進  | `修改說明.md`（） |

---

## §一　Session 交接

### §一.1　產出 handoff.md

**觸發時機**：一輪工作告段落（全目標審查完、全稿複查過、或使用者要換 session），**不論 context 是否充裕，固定執行**。

**存放路徑**：`{work_dir}/handoff.md`（剛完成的工作區內，與該輪其他產出物並列）。

**格式**（通用骨架；`{}` 內依當前階段與進度填入，不寫死階段）：

```markdown
# 交接文件

## 作品資訊
- 角色名：{角色名}
- 作品名：{作品名}
- 階段：{階段}　模型：{model}　{其他：如迭代總次數 loop_total（若適用）}

## 當前進度
- 已完成：{已完成範圍，如 Loop N / loop_total，或已處理目標清單}
- 下一步：{下一輪要做什麼}

## 關鍵檔案路徑
- 故事文件：`{路徑}`
- 參考資料：`{路徑}`（若有）
- {本階段必要檔，如合併草稿／素材清單／來源稿}：`{路徑}`
- 下一輪工作區：`{路徑}`

## 本輪工作摘要
各目標結果：
- {目標1}：{PASS / MINOR / MAJOR / FAIL}
- {目標2}：...

主要問題方向：{一句話說明本輪最需改進的重點，來自修改說明.md 的「整體方向」欄位（若有）}

## 撰寫心得彙整

（PASS / MINOR 目標各一節；MAJOR / FAIL 省略）

### {目標}　撰寫心得
1. **原意**：我原本打算怎麼寫（具體的寫法或表現方向）
2. **卡點**：遇到哪條規範或限制，導致原意無法執行（引用規範名稱或條目）
3. **處理**：最終選擇用什麼方法來處理

## 本輪調整紀錄

## 新 session 接手指令

請在新對話中輸入以下內容，Claude 將自行讀取所有必要檔案：

> 請繼續 {階段} {進度}，交接文件路徑：
> `{work_dir}/handoff.md`
> 接手後：依序讀「關鍵檔案路徑」中所有檔案 → 讀 `{要接手的 skill 路徑}` → 從 `{step}` 續。
```

### §一.2　接手新 session

**觸發條件**：新 session 收到接手指令（含 handoff 路徑，並指定要接手的 skill 與 step）。

**接手步驟**：
1. 讀取 `{handoff_path}`（handoff.md），確認作品資訊與當前進度。
2. 依序讀「關鍵檔案路徑」中的所有文件。
3. 讀接手指令指定的 `{要接手的 skill 路徑}`，從指定的 `{step}` 續。

> 本 skill **不預設**讀哪個 skill、從哪個 step 續——一切以 handoff 的接手指令為準。各階段 skill 的路徑與接續點在產出 handoff 時寫進接手指令。

### §一.3　產出後告知使用者

```
handoff.md 已產出至 {work_dir}/handoff.md

若要繼續，請開新 session 並輸入：
{接手指令}
```

## §二　Loop 迭代交接

### §二.1　產出 修改說明.md

**觸發時機**：subagent 做完一輪、要派下一輪 subagent 時（同 session 內）。最後一輪也預設產出（以防日後追加迭代）。

**存放路徑**：`{work_dir}/{下一輪}_修改說明.md`。

**格式**：

```markdown
# {下一輪} 修改說明

本文件列主 agent 從 checker 符合性報告與 reviewer 品質建議採納的問題，並記錄人類意見，供下一輪改進參考。

## 各目標問題

### {目標1}
- [MINOR] {類別}：{具體問題描述}
- [MAJOR] {類別}：{具體問題描述}

### {目標2}
...

## 整體方向

{不超過三句話，聚焦跨目標共通問題或最影響品質的單一問題}
```

## 撰寫規則

- **撰寫心得**：每目標審查結果為 PASS 或 MINOR 時，由寫手（claude subagent 或外部模型）輸出該目標心得，主 agent 彙整寫入 handoff.md；MAJOR / FAIL 不填（視為尚未完成或需重寫）。
- **工作摘要**：各目標結果直接從逐目標審查紀錄轉錄；「主要問題方向」從修改說明.md 的「整體方向」欄位直接引用（若有）。
- **接手指令**：固定格式，變數替換後填入；必須帶「要接手的 skill 路徑＋接續 step」，新 session 據此接手，本 skill 不預設。
