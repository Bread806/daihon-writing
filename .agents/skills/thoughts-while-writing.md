# 動筆時的思考

當你需要撰寫或修改劇本內文時，在動筆前必須走完以下思考流程。這個流程的目的是確保你寫出的每一段文字都錨定在角色設定、服務對象、當前情境之上，而非憑空發揮。

## 步驟 1：了解角色

閱讀該作品的故事文件，掌握角色的完整設定（角色小傳、主角、內在問題、外在問題、想要、需要等）。


## 步驟 2：確認服務對象

判斷這部作品的類型：

- **商業作品**：服務對象是聽眾（喜歡日本 ACG 文化、Vtuber 文化、情色文學的男性聽眾）
  - 撰寫時強調角色的**外在魅力**，角色要做出吸引聽眾的行為
- **創作類型**：服務對象是作者本身
  - 撰寫時強調角色的**內在變化**，角色要做出挑戰內在問題或課題的行動

若使用者沒有特別說明要強調哪個面向，依上述預設處理。

## 步驟 3：閱讀上下文理解現狀

往上閱讀前文約 20 行，確認以下三件事：

- **地點**：角色現在在哪裡（床上、教室、客廳沙發……）
- **動作**：角色正在做什麼（躺在聽眾懷裡、坐在聽眾身上、正面抱著聽眾……）
- **心情**：角色當下的情緒狀態（剛告白完所以心情舒坦、被看到所以害羞、被稱讚所以不知所措……）

## 步驟 4：規劃撰寫內容

這是核心設計步驟，分四個動作：

### 4-1. 找到開頭行為

從前文中取 1 個**與前文有關連性但尚未出現**的物品或事件，作為新段落的切入點。

> 例：前文主角正抱著聽眾安慰聽眾 → 因為抱著所以「對方身上的味道」是有關連但沒出現的事 → 「因為抱著對方，所以聞到對方身上的香氣」可以成為開頭行為

### 4-2. 結合使用者指示

將開頭行為與使用者給的情節方向結合。

> 例：使用者希望情侶打鬧 + 開頭行為是聞到香氣 → 用「身上的味道很香」引發打鬧互動

### 4-3. 設計循環情節

以下列結構設計情節循環：

```
角色做出開頭行為 → 聽眾的反應 → 角色見到反應的回覆
```

這個循環可以重複數次，每次的「行為」承接上一輪的「回覆」自然延伸。

**商業作品範例**（情侶打鬧、外在魅力）：
```
抱著你才發現，你身上味道好香哦          ← 開頭行為
(聽眾感到害羞)                          ← 聽眾的反應
嗯？不願意讓我聞哦。明明你都一邊抱著一邊聞那麼久了，好不公平喔。 ← 角色回覆
不理你了，我要轉過去睡覺了。            ← 行為
(聽眾急忙答應)                          ← 聽眾的反應
**笑了出來** 其實很想被我抱緊緊疼愛對吧？ ← 角色回覆
那我就再抱緊一點。                      ← 行為
```

**創作類型範例**（家人般的擔心、內在變化）：
```
你突然離家出走，今晚之後有地方住嗎？     ← 開頭行為
(聽眾無奈搖搖頭)                        ← 聽眾的反應
是哦…… 你這樣接下來的幾天應該也很不容易吧 ← 角色回覆
不然你就先借住我家吧。                  ← 過渡
這些錢雖然不多，不過你就先拿著吧        ← 行為
(聽眾驚訝地看著主角)                    ← 聽眾的反應
可以啦，我現在有工作，你還只是學生而已不用計較這些。 ← 角色回覆
要不要先把衣服換下來洗個澡，流浪一整天很累了吧？ ← 行為
(聽眾真誠地點點頭)                      ← 聽眾的反應
不過能你能穿的應該只有我公司的制服，你不介意吧。 ← 角色回覆
我拿來給你看，等我一下。                ← 行為
```

### 4-4. 設計潛台詞

潛台詞不是「寫」出來的，而是把角色真實的態度**藏**進台詞裡。

**第一步：寫出角色的真實態度**
不管角色說不說得出口，先把他真正想說的話直接寫下來。這不會出現在劇本裡，只是確認這個段落的潛台詞是什麼。

> 例：角色真正想說的是「我捨不得你走」

**第二步：把這句話藏起來**
找一件此刻現場存在的具體事物或動作，讓角色透過它來表達，而不是直說。

> 例：「捨不得你走」→ 角色一直幫聽眾整理圍巾，整理完又整理一次

**第三步：確認藏得夠不夠**
檢查台詞有沒有直接說出情感或動機。如果有，重寫成行動或具體的事。

```
✗ 我很捨不得你走。
✓ 你的圍巾歪掉了。
  **幫你把圍巾整好。**
  ⋯⋯還有點冷，你等一下。
```

## 步驟 5：動筆前的最後確認

在實際輸出前，逐條檢查：

- 設計的行為與回覆是否符合故事文件中主角的「行為與行動」設定
- 重要台詞的潛台詞能否追溯到故事文件的 Want 或 Need
- 台詞中若聲稱某樣東西「更重要」「最在意」，能否從故事文件或前文找到支撐該重量的具體依據
- 服務對象是否明確（外在魅力 vs 內在變化）
- 有疑惑之處向使用者提問釐清
- 若確認後需要修正，返回步驟 4 重新規劃

**修改既有稿件時，檢查範圍是整份稿件，不只是本次修改的段落。** 沒有被指出問題的段落，同樣需要逐條掃過。
