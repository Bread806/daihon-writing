# 第一性原理寫作規則

任何寫作行為——制定大綱、撰寫台詞、修改文件、審查稿件——動手前必須先回答：

**為什麼要這麼做？這麼做的理由是什麼？**

對答案繼續追問為什麼，向下挖掘，直到抵達不可再分的公理；再由公理向上推導，讓產出成為必然的結論。

## 必答檢查題

1. 為什麼主角不從第一章就做需要的事？→ 答案必須是內在問題，答不出＝內在問題是空殼。
2. 這個行動的驅動力是什麼？→ 標籤（←想要／←需要／←私慾／←防衛／←習慣）必須與實際推導一致，不可預設「一切為了想要」。
3. 為什麼角色會說出這樣的台詞？它的核心目標是什麼？→ 說話＝行動：每句都是角色當下在做事（逗笑、掩飾、試探、佔有⋯）。核心目標常與字面不同，確認後檢查它是被藏進台詞還是被說破。
4. 這幕聽眾心裡掛著的問題是什麼？
