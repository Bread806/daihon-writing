# 寫作方法論

## 使用說明

本方法論的故事文件對照項目供 **checker** 檢驗正文是否與設定一致；下列「商業品質四軸」供 **reviewer** 評核可聽性。兩者各出獨立結果，由主 agent 彙整。
每個面向皆以「故事文件中作者的設定」為對照基準，確認正文是否有效呈現。

檢驗順序建議：角色小傳 → 主角 → 主旨 → 想要 → 需要 → 內在問題 → 外在問題 →  情節 → 結局

>

---

## 商業品質四軸（核心判準）

以下四軸可用於檢視作品品質。

| 軸 | 定義 | 量測方式 |
|----|------|---------|
| **口語自然度** | 每句唸出來像人話，無散文腔、無解說腔、無術語腔 | 朗讀測試：連續三句唸出戲即不過 |
| **暢通度** | 聽一遍就懂、不重複、節奏不卡 | 數「⋯⋯留白被補成台詞」與同義反覆處 |
| **遐想空間** | 高潮與關鍵反應不說死，留給聲優與聽眾腦補 | 高潮許可／射精／關鍵反應處，台詞是否退位給 SE 與反應音 |
| **帶入感** | 聽眾的身體反應與沉默持續被接住 | 「行動→聽眾反應→回覆」結構完整＋沉默被詮釋 |

## 角色小傳

### 描述
角色在劇情發生前的所有背景設定，是主角一切行為的根源。包含身分、性格特徵、價值觀、條件（強弱項）、課題。

### 準則
以故事文件的角色欄位為基準：

1. **身分與標籤是否在正文中可辨認**
   - 讀者在未看故事文件的情況下，能否從正文的場景與台詞判斷出角色的標籤化特質（性別、職業、年齡、性向、標籤化的特質）
   - 標籤不應由旁白「說明」，而應由角色的行為「展現」

2. **性格特徵是否有具體行為支撐**
   - 故事文件設定了哪些性格特徵？正文中是否有對應場景或台詞將它「演出來」，而非只是描述它存在
   - **檢驗方式：遮住故事文件，讀者能否只憑正文說出角色的記憶點**

3. **角色的條件是否在正文中有機會可見**
   - 故事文件設定的強項，正文是否安排了讓它被看見的場景
   - 故事文件設定的弱項，正文是否有對應的困境讓它顯現

   - 讀者在未看故事文件的情況下，能否從正文的場景與台詞判斷出角色的標籤化特質（性別、職業、年齡、性向、標籤化的特質）

2. **性格特徵是否有具體行為支撐**
   - 故事文件設定了哪些性格特徵？正文中是否有對應場景或台詞將它「演出來」，而非只是描述它存在
   - **檢驗方式：遮住故事文件，讀者能否只憑正文說出角色的記憶點**

3. **角色的條件是否在正文中有機會可見**
   - 故事文件設定的強項，正文是否安排了讓它被看見的場景
   - 故事文件設定的弱項，正文是否有對應的困境讓它顯現

4. **角色的課題是否在正文起點已埋下**［Should］
   - 角色小傳中設定的課題，應在正文早期出現尚未解決或尚未滿足的狀態
   - 課題的起點不是角色在說它，而是讀者能觀察到角色還做不到、還卡住的樣子
   - 是否與主旨、情節扣合
    
5. **角色的價值觀是否體現在正文中**
   - 角色對人事物的看法與重視的東西能否被觀察到

## 主角

### 描述
在劇情裡角色是個怎麼樣的人，與主旨、情節三面一體。是角色小傳的延伸，在故事中透過行為與行動體現。

### 準則
以故事文件的「角色行為」設定為基準：

1. **行為模式是否落實在正文中**
   - 故事文件列出的角色行為（如：裝可愛、吐槽、搞笑、偶爾誠懇），正文中是否有對應的台詞或動作
   - 正文中主角的實際言行，是否與故事文件的行為描述吻合
   - 故事文件描述了角色在特定情緒下的策略（如：煩惱藏心裡、用搞怪包裝真實情感），正文遇到對應情境時，角色是否採取一致的策略

2. **角色具備的任務是否在正文中持續推進**
   - 需要賦予角色明確的任務，這會決定故事的類型

3. **行動是否與價值觀連動**
   - 正文中主角做出的重要行動，能否從角色的價值觀中找到合理的動機
   - 正文中是否至少有一個場景，讓主角的行動直接反映他最核心的在乎
   - **若行動的動機不明，需回到角色小傳確認是否有鋪墊遺漏**

4. **角色面向是否充足**
   - 主角是否不只有一個面向？正文中是否有場景呈現角色「表裡不一」卻合理的一面
   - 多面向不代表矛盾，而是同一個角色在不同情境下的不同策略
   
5. **場景與情節是否對角色有積極作用**
   - 場景：呈現角色面向的媒介，是角色塑造的好機會。場景與場景間的連結性非常重要

## 想要（Want）

### 描述
貫穿全劇的具體目標，是角色行動的表層驅動力。類似角色的「任務」——明確、可見、能推動情節前進。

### 準則
以故事文件中可推論的主角具體目標為基準：

1. **想要在正文中是否具體且清晰可見**
   - 讀者能否從正文的行為或態度判斷出主角此刻在追求什麼
   - 想要不必由角色直接說出，但需讓讀者感知到方向
   - **若讀者讀完某章節仍無法判斷主角在追求什麼，該章節可能缺乏驅動力**

2. **各章節的子目標是否清楚且有推進感**
   - 每個章節的主角是否都有一個明確的「當下想要」
   - 各章節的子目標是否朝大目標逐步推進，而非原地踏步

3. **想要是否對情節產生實際推力**
   - 正文中主角的行動，是否因「想要某件事」而產生，而非憑空發生
   - 若某情節裡主角是完全被動的，需確認是否為刻意設計（想要受阻），而非缺乏動機

## 需要（Need）

### 描述
主角真正需要學會的事，是故事最終要帶領角色抵達的內在改變。與「想要」不同——想要是角色意識到的目標，需要是角色尚未意識到、卻最終必須面對的成長。

### 準則［Should］
以故事文件中主旨所描述的角色成長方向為基準。動機／成長類檢查整體降為 Should：**只擋「觸發斷裂」**（情感揭露、語氣轉換、突然的親近無觸發點 → MAJOR），鋪陳深度不再列品質扣分項：

1. **需要是否在正文中能被窺見**（Should）
   - 需要在故事起點不應被滿足，而是透過角色做不到某件事、迴避某個時刻、產生矛盾來暗示存在
   - 正文中是否有場景讓讀者感受到主角「還不具備」需要所描述的能力或認知

2. **想要與需要是否形成張力**（Should）
   - 主角追求「想要」的過程，是否間接暴露了「需要」尚未被滿足的困境
   - 正文中是否有時刻讓讀者感受到「角色得到了想要的東西，但顯然還缺少了什麼」

3. **需要的轉變軌跡是否有前期鋪墊**（Should）
   - 若正文已推進到角色開始改變的章節，改變是否有早期場景作為對比的起點支撐
   - 若改變顯得突然，需確認前期是否有足夠的「需要尚未滿足」的積累，或需要的事物是否清楚定義

## 內在問題

### 描述
角色在劇中真正需要解決的問題，與角色的價值觀緊緊扣合。是需要的根源，也是主旨的對照面。

### 準則［Should］
以故事文件的「主角的內在問題」欄位為基準。內在問題檢查降為 Should——商業音聲作品的決勝點是帶入感與遐想空間，不是心理深度：

1. **內在問題在正文中是否可被感知**（Should）
   - 讀者不需看故事文件，能否從正文的行為、台詞、情境中隱約感受到主角的內在問題
   - **不是指角色說出內在問題，而是正文有場景讓讀者「觀察到問題存在」**

2. **內在問題是否貫穿始終且穩定**（Should）
   - 故事文件設定的內在問題，在正文各章節是否持續有跡可循
   - 若正文中途浮現了故事文件未提到的「新內在問題」，需確認是設定遺漏還是刻意延伸

## 外在問題

### 描述
劇中表層、具體、可見的問題，為情節提供時限與壓力。與情節、題材息息相關。

### 準則
以故事文件的「迫切的外在問題」欄位為基準：

1. **威脅性是否在正文中被感受到**
   - 讀者能否從正文清楚感知到這個問題的嚴重性
   - 若正文描述讓外在問題顯得輕描淡寫，需確認份量是否足夠

2. **時效性是否被落實**
   - 故事文件設定的時限，是否在正文中被明確提及或隱含
   - 時限是否對角色的行動產生了具體的壓迫感，而非只是背景資訊

3. **外在問題是否與內在問題形成連動**
   - 外在問題的存在，是否迫使角色的內在問題浮出水面
   - 正文中是否有場景呈現「因為外在問題，內在問題變得無法迴避」
   - **這個連動是情節張力的核心，若兩者完全平行而無交集，需重新檢視**

## 主旨

### 描述
作者希望讀者/聽眾從故事中收穫的東西。包含題材（外殼）與類型（內容實際呈現的樣貌）兩個層次。與 主角、情節 是一體三面的關係。

### 準則
以故事文件的「主旨」欄位為基準：

1. **題材與類型是否被正文落實**
   - 故事文件定義的題材與類型，正文的整體走向是否朝此方向發展
   - **讀者若不看故事文件，能否從正文感知到這個故事的題材與類型**
   - 故事文件設定的類型（如：成長類型），正文的情節結構是否真的在讓角色成長

2. **作者的預期收穫是否能在正文中被觸發**
   - 故事文件中寫下的聽眾預期體驗，正文是否有對應的場景設計來觸發
   - 若預期收穫有多項，逐一確認正文中各自是否有觸發點

3. **主旨的方向性是否在正文中可見**
   - 主旨描述的是角色「最終會抵達的地方」，正文是否讓讀者感受到角色距離這個終點仍有距離（主旨尚未完成的狀態）
   - 主旨可以在故事開頭就被主角說出或完成，但須注意是否透過情節完備
   
4. **主旨是否有帶動情節發展**

## 情節

### 描述
故事的現在。情節與主角一體兩面，互相決定。每一個情節都應服務於角色的認識或改變，無關角色的情節即是多餘的。

### 準則
以故事文件的「各章節概述」與各章節「主旨」欄位為基準：

1. **各章節的敘事目標是否被執行**
   - 故事文件每個章節都標注了該章節要達到的敘事目標，正文的情節是否有效達成
   - **比對方式：先看章節的敘事目標，再看正文是否有對應的設計可以觸發它**

2. **情節的因果是否符合角色設定**（Must-not-fail 底線）
   - 正文中每個情節的發生原因，能否從角色的價值觀或處境找到合理依據
   - 若情節顯得突兀，需回到角色小傳確認是否有鋪墊遺漏
   - **情節發生的原因，應挑戰或吻合角色的價值觀——先確認吻合，若不吻合再確認是否為刻意挑戰**

3. **情節的篇幅是否聚焦**
   - 正文是否有大量篇幅花在與主旨、內在問題、外在問題無關的內容上
   - 若有，需確認這些內容是否間接服務了角色的認識——若否，即為偏題

> **v3.1 補註**：情節篇幅聚焦的判準放寬——與主旨無直接關係、但服務「帶入感與互動節拍」的內容（閒聊、逗弄、日常感）不算偏題。商業音聲的「偏題」判準是：該段是否破壞節奏或角色一致性，而非是否直接服務主旨。

## 結局

### 描述
故事的終點，是主旨最直接的體現，也是主角需要是否被實現的最終呈現。

### 準則
以故事文件的主旨與角色成長方向為基準：

1. **結局類型是否與故事文件一致**
   - 根據故事文件的主旨，這個故事應屬於哪一種結局類型（成長／尋回／和解／失落）
   - 正文的走向是否朝向這個結局類型發展，而非滑向另一種

2. **結局是否從「需要」的實現中自然生長**
   - 結局的到來，是否因為主角終於做到了「需要」所描述的那件事
   - 若結局的解決方式與角色的需要無關，需確認是否流於外力解決（外在問題消失）而非內在成長

3. **結局與開頭是否形成對比**
   - 主角在故事起點的狀態（內在問題尚存、需要尚未滿足），與結局的狀態是否形成可見的對比
   - 這個對比不需要靠旁白說明，應能從角色的行為或選擇中直接感受到
